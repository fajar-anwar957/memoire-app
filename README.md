# Mémoire

**An AI-powered memory companion for people living with early-stage dementia.**

Mémoire is a privacy-first web application that combines a conversational AI companion with evidence-based Cognitive Stimulation Therapy (CST) activities. It is designed around the needs of older adults with mild to moderate dementia: large touch targets, gentle non-judgemental feedback, voice support, and a strict no-scores philosophy — encouragement, never assessment.

> Final Year Project — BSc (Hons) Computer Science, University of Hertfordshire.

---

## Key Features

### AI Companion
A warm, patient conversational companion powered by the Claude API. The companion is aware of the user's profile, important people, and logged memories — enabling natural, personally meaningful conversation — while **no personally identifiable information ever leaves the device in raw form** (see [Privacy by Design](#privacy-by-design)).

### CST Activities
Three daily activities grounded in Cognitive Stimulation Therapy, the non-pharmacological intervention recommended by NICE guideline NG97 for mild to moderate dementia:

| Activity | Description |
|---|---|
| **Daily Quiz** | Five gentle multiple-choice questions generated each day — orientation questions (day, season, time of day) computed locally, plus personalised reminiscence questions generated by AI from the user's own memories and people. |
| **Photo Recall** | Family photos are shown with three name options, prompting recognition of loved ones with supportive, pressure-free feedback. |
| **Word Association** | A prompt word and image invite associative responses by voice or text, sparking connections and conversation. |

**Design principle:** no numeric scores, streaks, percentages, or tallies appear anywhere. Feedback is exclusively non-numeric and positive — colour cues, stars, flowers, and encouraging phrases. Incorrect answers are never marked "wrong"; the correct answer is gently highlighted instead, following errorless-learning principles.

### Memory Log — *Memories & People*
A simple space to record daily moments (with optional photos) and the special people in the user's life. Entries feed the AI companion's context and the Daily Quiz. Destructive actions (edit/delete) are hidden behind an explicit edit mode to prevent accidental taps.

### Emergency Contacts & Quick Call
Emergency contacts are managed through the Profile and are always one tap away via a persistent quick-call button with `tel:` dialling.

### Voice Support
Text-to-speech via the Web Speech API on every activity card and result popup — always user-initiated (tap to hear, tap to stop), never auto-playing, with a slowed speaking rate and natural pauses between segments for comfortable listening.

## Privacy by Design

Mémoire handles some of the most sensitive data imaginable — the memories and relationships of a vulnerable user group. The architecture reflects that:

- **localStorage-only persistence.** There is no backend database and no server-side storage. All profile data, memories, people, and photos remain on the user's device.
- **Client-side pseudonymisation.** Before any text is sent to the Claude API, known entities (the user's name, family members, friends) are substituted with anonymous tokens (`PATIENT`, `FAMILY_1`, `FAMILY_2`, …) on the device. Responses are de-pseudonymised locally before display. Real names never reach the API.
- **Hallucination guards.** AI-generated quiz content is validated client-side: questions containing unresolved tokens or invented details are discarded and replaced from a local fallback bank.
- **On-device speech.** Voice features use the browser's built-in Web Speech API — no third-party voice service receives any audio or text.
- **Image compression.** Photos are resized via canvas before storage to respect mobile localStorage quotas, with quota errors surfaced to the user rather than failing silently.

This approach is informed by GDPR Articles 25 and 32 (data protection by design and by default; pseudonymisation as a security measure).

## Getting Started

### Prerequisites
- Python 3.12+
- An Anthropic API key

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/fajar-anwar957/memoire-app.git
cd memoire-app

# 2. Create and activate a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure your API key
# Create a .env file in the project root:
echo "ANTHROPIC_API_KEY=your-key-here" > .env

# 5. Run the application
flask run
```

The app will be available at `http://127.0.0.1:5000`.

> **Note:** Never commit your `.env` file or API key. The key is used server-side by the Flask proxy only.

## Accessibility & Dementia-Friendly Design

- Minimum 16px text and 44px tap targets throughout
- High-contrast warm palette (cream / navy / orange) chosen for readability
- One question or task per screen; gentle transitions, nothing fast or startling
- A "**I'm done for today**" exit on every activity popup — the user is never trapped in a flow (user control and freedom)
- Language is always warm and non-clinical; the words "wrong", "error", and "score" never appear in the patient-facing UI

## Academic Context

Mémoire is developed as a final year BSc Computer Science project at the University of Hertfordshire. Its design decisions are grounded in the CST literature (Spector et al.; NICE NG97) and the iCST digital adaptation research (Rai et al., 2020 — *Thinkability*, JMIR Aging), with privacy architecture informed by GDPR data-protection-by-design principles.

This is a research prototype and **not a medical device**. It is not intended to diagnose, treat, or replace professional dementia care.
